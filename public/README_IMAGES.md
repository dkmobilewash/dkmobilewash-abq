## How to Fix

1. Locate your original image files from your backup or production server

4. Rebuild the project with `npm run build`

## Image Specifications (Recommended)

- **Hero/Banner Images**: 1920x1080px or larger, optimized for web
- **Service Package Images**: 800x600px minimum
- **Gallery Images**: 1200x800px minimum
- **Before/After Images**: 800x600px minimum
- **Format**: JPEG (85-90% quality) or optimized PNG
- **File Size**: Keep under 500KB per image for best performance
